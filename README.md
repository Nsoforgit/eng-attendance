# EngAttend — Engineering Biometric Attendance & 70% HOD Exam Eligibility Platform (300L–500L)

Production web application and Progressive Web App (PWA) for **Faculty of Engineering Departmental Core Courses (300 Level, 400 Level, and 500 Level)**.

## Key Features
- **Multi-Department Registry:** Supports Petroleum, Mechanical, Electrical/Electronics, Civil, Computer, and Chemical Engineering, plus instant HOD registration for additional departments.
- **Role Hierarchy:**
  1. **Department HOD:** Full 70% Exam Eligibility Matrix across 300L, 400L, and 500L core courses, CSV export, and printable official Exam Clearance sheets.
  2. **Course Lecturer:** Starts and locks live lecture attendance sessions.
  3. **Level Course Rep (300L, 400L, 500L):** Enrolls student biometrics, runs the Samsung Smartphone Camera Biometric Kiosk, and manages **Offline-First Sync** when lecture hall network drops.
  4. **Student Portal:** Real-time attendance percentage tracking and WebAuthn Smartphone Fingerprint Passkey check-in.
- **Zero External USB Hardware Required:** Uses on-device Face Biometric vectors + Smartphone WebAuthn Passkeys.
